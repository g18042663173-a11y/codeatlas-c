主对照为 Wiki 自由阅读相对源码组。先平均题内三次重复，再按仓库内机制等权、两仓库等权汇总；40 道代码题覆盖 35 个机制。8 道拒答题另列，不加入代码机制差值。

可以说：**这批固定任务观察到回答要点更完整。** 不能说：已经证明稳定正确率提升。主指标区间跨零，且未达到预登记的 10pt 阈值；lwIP 单仓库的正向观察不能代替两仓库主结果。完整度是次指标，仍受同模型 AI 复核和固定任务范围限制。

原始 432 个 Wiki 试次中有 115 次降级为证据包，95 次属于规划 JSON 解析失败，原生规划门禁没有通过。真实 usage 不完整，不报告 Wiki token 节省。此次修复评分链路，不把既有 Agent 规划缺陷说成已经修好。
