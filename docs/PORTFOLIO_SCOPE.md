# 公开作品集边界

## 可以公开展示

- 固定 commit 的 cJSON、lwIP 和仓库内置 C fixture；
- 6 条 CC0 合成会话及其质量评估；
- 编译器事实、分层 Wiki、证据包、只读 Agent 轨迹；
- 人工维护知识卡的审核、失效、替代历史；
- 117 道旧检索回归题、40 道正式人工开发任务和 6 个安全闭环场景；
- 由当前代码实际生成的成功指标与失败案例。

## 当前验收已满足

1. cJSON/lwIP 使用固定 revision 和 compile database 正式解析，严重编译诊断为 0。
2. 代码结论返回 repository、revision、USR、文件范围和来源类型。
3. candidate、未审核卡、stale 卡、superseded 卡和原始会话都不会进入确定结论。
4. Agent 只调用六种只读工具，最多六步；概念/功能题 Wiki-first，模型异常会可见回退。
5. 六个闭环场景的工具、锚点、审核/QA/失效/替代/重建和拒答门禁均通过，原始会话入检索为 0。
6. cJSON/lwIP 的 10 道人工开发检索均为 10/10，Recall@10 相对 BM25 分别提升 10/20pt，MRR 均上升；40 题当前为 30/40，剩余十题全部是等待用户审核 B 卡的 `blocked_by_review`，真实检索失败为 0。旧 117 题回归消融采用另一题集，不能混写成同一个 +40pt 指标。

## 不能包装成已完成

- 多用户团队知识中心、权限审计和生产运维；
- 自动抓取内部会话、工单、录音或聊天记录；
- IDE/MCP 插件和自动代码修改；
- 完整控制流、数据流或函数指针分析；
- 真实模型 A/B/C 效果——仓库目前没有真实模型实测报告；
- PPT 中的内部规模、截图、人员信息和“1.56 倍”等历史数字。

Key 只能来自 `LLM_BASE_URL / LLM_MODEL / LLM_API_KEY` 环境变量，不得写入样例、数据库、报告或运行轨迹。两张真实卡在用户确认前保持 `ai_assisted_draft / pending`，QA reviewer 为空。
